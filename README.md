# LearningDITA 中文版

[LearningDITA] 是 [美国Scriptorium出版服务公司][Scriptorium] 开发的一门开源的 DITA 入门课程。该课程自 2015 年上线以来深受 DITA 用户的欢迎。截至 2024 年底，[LearningDITA网站] 的注册用户已经超过 1.6 万人。

LearningDITA 共有九节课，每课又分为若干讲，内容全面又细致入微。如果你是 DITA 小白，可以把它当作入门课程；如果你已经对 DITA 有所了解或者有了一些使用经验，可以通过它进一步巩固和提高实际场景下的应用技能。

LearningDITA 中文版不仅仅是对英文原版内容的翻译，也对部分课程的内容进行了一些优化。例如，对内容较多的课程进一步细化了章节划分，使课程的内容结构更加清晰；课后的拓展资料更换为精选的中文资料，使国内用户在访问和阅读时更加便捷。

如果你喜欢本课程，欢迎将它分享给你的亲友、同事和同行。如果你在学习过程中遇到任何疑问、发现任何问题或者想到任何改进建议，欢迎到 [LearningDITA中文版GitHub存储库] 提交问题报告 (Issue)或者在 [微信公众号@技术传播百态说] 和同名 [知乎专栏] 给我留言。
