# 什么是元数据?

**元数据**是指关于数据的数据，为信息提供信息。在 DITA 中，你可以为主题、元素等很多类型的内容设置元数据。

例如，文件属性就是文字处理软件为每个文件生成的元数据。你可以从文件属性中知道这个文件的创建者是谁、最后一次修改的时间等。读者阅读文件时，不会看到文件属性中的信息（作者和最后修改日期等）。文件属性只是关于文件本身的元数据。

你可以利用元数据对内容进行各种分类。例如：

- 标注文档类型，比如“白皮书”或“建议”。
- 将内容与具体的产品（或产品编号）关联在一起。
- 说明用户级别，比如“初级用户”、“中级用户”或“专业用户”。
- 说明目标受众，比如“经理”或“员工”。
- 说明主题的状态，比如“草稿”、“审阅中”或“终稿”。
- 说明内容的失效时间。

设置了元数据之后，你和读者就可以：

- 更高效地查找内容
- 更有效的管理内容（比如，什么时候将内容公开或者从网站中删除）
- 提供个性化内容（比如，读者可以筛选只适合新手查看的内容）
- 根据不同的交付要求筛选内容（比如，Windows 版或 Macintosh 版）
- 更高效地复用内容
- 说明内容使用的语言
- 管理项目进度

XML 文件在主题内部为元数据编码，不是在主题层面就是在具体的元素上。你可以利用这些元数据来管理或处理 DITA 文件中的内容。

在 DITA 中，每个主题必须有一项元数据：`id` 属性。内容编辑工具或内容管理系统一般会给每个主题都自动生成一个ID（`id` 属性的属性值）。这是一个带有`id` 属性的主题示例：

```xml
<topic id="xyz">
   <title>请将主题的标题放在这里</title>
   <body>
      ....
   </body>
</topic>
```

其他元素也可以设置 `id` 属性。例如，如果你为一个表格设置了 `id` 属性，你就能创建指向它的交叉引用。大多数内容编辑工具都会为经常被交叉引用的元素自动分配 ID。

你所在的企业或你使用的 DITA 管理系统可能还需要其他元数据。例如，使用 `xml:lang` 属性为主题设置语言就是很常见的做法。

```xml
<topic id="xyz" xml:lang="en-US">
<topic id="abc" xml:lang="zh-CN">
```

通常，读者是看不到元数据的，他们只能看到筛选结果中的内容。除此之外，读者也可以使用元数据查找内容。
