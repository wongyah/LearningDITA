# 通用型主题

通用型主题是其他所有主题类型的基础。其他的主题类型都是在通用型主题的基础上定制而来的。通用型主题中的许多元素和内容组织方式，也能用在其他的主题类型中。

在 DITA 中，所有的主题都有一个基本结构：

```xml
<topic id="sample">
  <title>将主题的标题放在这里</title>
  <shortdesc>一段简要描述</shortdesc>
  <body>
    （将大部分元素放在这里。）
  </body>
</topic>
```

在上面的代码中，各元素的用途如下：

- `<shortdesc>`（简要描述）元素使用两到三句话总结主题的主要内容。
- 在一个主题中，`<title>` 是唯一一个必选元素。
- 主题的正文放在 `<body>` 元素中。在其他类型的主题中，`<body>` 元素的名称会相应的变化一下。比如，在概念型主题中叫 `<conbody>`，在任务型主题中叫 `<taskbody>`。

!!! note "注意"
    理论上，你可以使用通用型主题编写内容。不过，最好还是优先使用其他专用的主题类型，如概念型主题、任务型主题和参考型主题。

通用型主题中还有其他一些元素，不过上面这些元素是最常用的。
