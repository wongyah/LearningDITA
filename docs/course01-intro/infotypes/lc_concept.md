# 概念型主题

概念型主题主要用来说明“为什么”。它为读者提供关于某个话题的背景信息。

概念型主题经常使用段落和列表，有时也会使用注释、表格和图片等格式来加深读者对主题的理解。

概念型主题中的常用元素有：

`<conbody>`
: 概念型主题的正文

`<p>`
: 段落

`<ul>`
: 无序列表（也叫项目符号列表）

`<ol>`
: 有序列表（也叫数字列表）

`<li>`
: 无序列表或有序列表的列表项

`<fig>`
: 图片，可以包含一个图片标题

`<image>`
: 图片，可以位于 `<fig>` 元素中，也可以位于行内文本中。

`<section>`
: 主题中的一个子节，可以包含一个标题
