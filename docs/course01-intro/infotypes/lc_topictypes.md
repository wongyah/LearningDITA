# 主题类型

在 DITA 中，主题是内容的基本单位。

DITA 的一个基本原则是，不同类型的内容要放在不同的容器（主题类型）中。这样，我们就可以根据内容的类型来设计主题中的元素。

在 DITA 中，所有的主题类型都是从通用型主题衍生出来的。通用型主题经过“定制”之后，变成一个个专用的主题类型。每个专用的主题类型都有各自适配的内容类型。在 DITA 中，有以下几种“标准”的主题类型：

- 概念型主题 — 用来编写概念性内容，说明“为什么”。
- 任务型主题 — 用来编写一步步的操作说明，说明“怎么做”。
- 参考型主题 — 用来编写参考性信息，说明“这是什么”。
- 术语主题 — 用来定义一个术语，说明“这是什么意思”。

本节课程先介绍通用型主题，然后再逐个介绍标准的主题类型以及如何使用它们。
