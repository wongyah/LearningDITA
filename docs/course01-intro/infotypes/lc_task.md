# 任务型主题

任务型主题主要用来说明“怎么做”。它要手把手地教读者完成一项任务。在任务型主题中，可以为步骤提供操作结果方面的信息，也可以使用图片、注释以及子步骤（只允许嵌套一级）等格式。

技术内容通常以任务型主题为主。

在 DITA 中，任务型主题分为两种类型：

- 严谨任务主题
- 一般任务主题

在严谨任务主题中，所有元素必须按照特定的顺序出现，只允许使用比较正式的步骤元素（`<steps>` 或 `<steps-unordered>`），`<example>` 元素的数量不能超过一个。

一般任务主题也称为宽松任务主题，可以更加灵活的安排元素的顺序，可以使用多个 `<example>` 元素，还可以使用`<steps-informal>`元素编写操作步骤。`<steps-informal>` 元素中的内容，可以比另外两个步骤元素更加自由。

严谨任务主题适合编写分步骤的操作说明；一般任务主题适合编写流程概述。

严谨任务主题中的常用元素有：

- `<taskbody>` - 任务型主题的正文
- `<steps>` - 一系列操作
- `<step>` - 单个操作
  - `<cmd>` - 用户执行的操作。`<cmd>` 是 `<step>` 元素中唯一的必选元素。
  - `<info>` - 与一项操作有关的其他信息。
  - `<stepresult>` - 执行操作后产生的结果
  - `<stepxmp>` - 演示如何进行操作的示例
- `<example>` - 演示如何完成整个任务的示例
