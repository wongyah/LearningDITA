# DITA 定制

信息架构师可以通过 DITA 定制创建更适合企业或组织的元素和属性。DITA 定制是基于现有的元素创建新元素的。

企业或组织经常通过 DITA 定制满足自己的个性化需求，比如：

- 通过创建新元素，为特定的内容定制内容结构。
- 通过创建新属性，识别特定内容。
- 通过重命名元素，使写作人员更容易理解和记忆。

例如，你可以定制一组 `<codeblock>` 元素来区分编程语言，比如创建新元素 `<codeblock-java>` 和 `<codeblock-php>`，分别用于编写 Java 代码示例和 PHP 代码示例。你也可以通过为 `<codeblock>` 元素创建语言属性来达到相同的目的：`<codeblock language="java">`或 `<codeblock language="php">`。

!!! important "重要"
    请谨慎使用 DITA 定制！DITA 定制可以让标签更加具体，同时也会增加实施和维护 DITA 的成本。你必须在二者之间做好利弊权衡。

除此之外，信息架构师还可以使用 DITA 约束来移除某些不需要的或者不想用的元素。例如，如果你们公司的文档不会涉及到软件代码，信息架构师就可以移除 `<codeblock`（代码块）和 `<codeph>`（行内代码）等元素。DITA 约束可以减少写作人员需要学习和记住的元素数量，使他们的工作轻松一些。
