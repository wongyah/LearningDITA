# 参考型主题

参考型主题主要用来说明“这是什么”。参考型主题一般使用描述性的语言阐述事实，比如描述命令或 API 函数调用的语法、使用表格说明设备的参数和误差或者使用表格说明软件界面上的项目。

参考型主题不能用来编写操作步骤或背景信息。参考型主题与字典中的词条类似，只提供事实性的说明信息。

参考型主题中的常用元素有：

`<refbody>`
: 参考型主题的正文

`<section>`
: 参考型主题中的一个子节，可以包含一个标题

`<table>`
: 表格

`<fig>`
: 图片，可以包含一个图片标题

`<properties>`
: 属性列表或参数列表

`<refsyn>`
: 语法分析图
