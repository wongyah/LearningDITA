# 结构化写作

结构化写作是一种可以定义文档中的内容组织方式并强制执行的发布流程。

DITA 元素具有非常明确的层级结构和相互关系。也就是说，DITA 对每个元素都做了明确的规定，比如它可以包含在哪些元素内，以及它可以包含哪些元素。DITA 还规定了，哪个元素可以（或必须）放在哪个元素的前面或后面，以及允许放多少个。

例如，DITA 中的简单表格可以有一个标题行，也可以没有标题行；如果有标题行，标题行的后面必须紧跟着一个或多个表格行。这条规则是为了防止写作人员将标题行混放在表格行之中，或者创建一个没有表格行的表格。

DITA 定义了这些规则，从而定义了内容结构。计算机程序也可以使用这些规则来检查 DITA 文档的内容结构是否正确。对于有特殊要求的文档，信息架构师可以定义自己的元素和规则。

尽管 DITA 应用得非常广泛，但它并不是唯一的结构化写作标准。DocBook、S1000D 和 NLM 等也属于结构化写作标准。
