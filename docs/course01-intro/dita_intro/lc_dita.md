# 什么是 DITA?

DITA 是达尔文信息类型化体系架构的简称，最初是由 IBM 开发的。2005 年，IBM 将 DITA 捐献给了结构化信息标准促进组织 ([OASIS])。之后，DITA 就变成了一个开放的标准。

DITA 可以用来编写、组织和管理内容。它是基于 XML 开发的内容架构，不依赖于任何软件工具。

DITA 的特点如下：

- 主题化写作
- 内容和格式分离
- 精益写作
- 结构化写作

“DITA 是一个基于 XML 的开放标准”意味着，有很多软件都可以用来创建、编辑、排版和保存 DITA 文件。当业务需求发生变化时，你可以根据自身需要随时更换软件。
