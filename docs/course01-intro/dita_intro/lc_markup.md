# 标记语言

DITA 是基于 XML 开发的内容架构。XML 是一种标记语言，可以保存为纯文本格式。也就是说，如果你使用的操作系统是 Windows，用记事本就可以编辑 XML 文件了。

XML 并不是唯一的标记语言。其他常见的标记语言还有 HTML、Markdown 和 LaTex 等。其中，大部分人最熟悉的可能是 HTML，它是网页开发的基础语言之一。

## XML 和 HTML 的共同点

XML 和 HTML 非常相似。它们都使用尖括号（`<`和`>`）作为标签的标记，比如 `<title>`。它们还都使用斜杠作为结束标签的标记，比如 `</title>`。

```xml
<title>这是一个标题</title>
```

和 HTML 一样， XML 也可以给标签添加属性。属性可以为标签中的内容提供附加信息，其格式为 `attribute="value"`。

```xml
<note type="warning">切勿将您的手臂和腿伸出车外！</note>
```

## XML 和 HTML 的区别

XML 和 HTML 之间的区别主要有两点：

- 在 XML 中，不能省略结束标签和属性值外面的引号。但在 HTML 中，结束标签和属性值外面的引号是可以省略的。
- 在 XML 中，你可以定义、修改或添加自己的标签。但在 HTML 中，只能使用预定义的标签，比如 `<body>`、`<p>` 或 `<span>`。

DITA 基于 XML 定义了一套自己的标签名称，即“元素”。DITA 中的元素名称一般都有明确的语义，可以清楚的表明元素的用途，比如标记注释信息用的 `<note>`、标记小节用的 `<section>` 和标记图片用的 `<image>`。不过，HTML 中也有一些语义明确的标签，它们也被引入到了 DITA 中，比如标记段落用的 `<p>`、标记无序列表用的 `<ul>` 和标记有序列表用的 `<ol>`。

DITA 和 HTML 之间还有一个不同点：HTML 文件的根元素（最外层标签）是 `<html>`，而 DITA 文件的根元素取决于主题的类型，比如 `<concept>`、`<task>`或 `<reference>` 等。

!!! tip "小贴士"
    现在的内容编辑工具都很智能。当你使用 DITA 编写内容时，内容编辑工具一般会帮你自动处理元素标签和属性，使它们合法有效。但了解 XML 和 DITA 中关于标签和属性的规定，仍然是非常必要的。
