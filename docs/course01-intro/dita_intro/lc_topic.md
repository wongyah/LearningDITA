# DITA 主题

在 DITA 中，**主题**是内容编写和内容复用的基本单位。

在主题化写作中，你可以创建许多单独的主题。每个主题只阐述一个想法或只回答一个问题。这些主题可以在多个文档中使用或复用，还可以以任何顺序排列组合。DITA使用**导图**将主题们组织在一起。导图相当于目录，可以用来安排主题的层次和顺序。

要提高主题的复用性，创建主题时请遵循以下原则：

- 每个主题只阐述一个想法或只回答一个问题。
- 每个主题必须独立成篇。
- 不要对主题的上下文做任何假设。例如，不要假设上一个主题或者下一个主题中会包含什么内容。
- 每个主题都保存为一个单独的文件。

每个主题必须包含且只能包含一个标题元素。每个主题的根元素必须有一个 `id` 属性。也就是说，一个合法的主题至少应该是这样的：

```xml
<topic id="sample">
  <title>请将主题的标题放在这里</title>
</topic> 
```

不过，一个真正的主题中肯定还会有其他的内容。
