# 交叉引用

你可以使用交叉引用创建指向图片、表格、网站或其他文本的链接。

使用 `<xref>` 元素创建交叉引用。`href` 属性可以用来设置交叉引用的目标位置。

在 `<xref>` 元素中，可以插入文本，也可以留空。如果插入了文本，这些文本就会成为链接文本。如果留空，链接目标的标题就会成为链接文本。

!!! note "注意"
    创建指向章节、图片或表格的交叉引用时，应该将章节、图片或表格设置为 `href` 属性的属性值。虽然有点反直觉，但千万不要将章节、图片或表格的 `<title>` 元素设置为 `href` 属性的属性值。

交叉引用也可以链接外部资源。如果链接目标是外部资源，`scope` 属性的属性值应设置为 `external`，`format` 属性的属性值应设置为外部资源的格式，就像这样：

```xml
<xref href="https://www.tcblabber.cn" scope="external" format="html"/>
```

!!! note "注意"
    如果链接目标是PDF文件，`format` 属性的属性值应设置为 `pdf`。

理论上讲，交叉引用确实可以在主题与主题之间创建链接。但使用交叉引用创建的链接属于内联链接，必须手动设置链接目录并手动维护。创建交叉引用时，源主题和目标主题必须位于同一个导图中。如果你在其他导图中重用了源主题，却没有重用目标主题，使用该导图发布的文档时源主题中的链接就会失效。而且，你在发布过程中可能不会收到任何错误报告。所以，最好不要使用交叉引用创建链接，而是使用关系表。
