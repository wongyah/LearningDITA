# 关于表格的最佳实践

在创建或编辑 DITA 表格时，请遵循以下最佳实践：

- 输入内容之前，在每个单元格（`<entry>`）中都插入一个 `<p>` 元素中。否则，表格的格式可能会出现异常。
- 在 DITA 中，表格的确可以嵌套，但你最好别这样用。
- 设计表格时，行数多一些无所谓，但一定要尽可能降低列数。否则，当你发布文档时，列数过多的表格可能会出现格式异常。
- 在许多文字处理软件中，人们经常使用表格来设置页面格式，比如缩进列表。但在 DITA 中，这种做法不但没有用，还可能导致一些格式异常。
- 表格中的内容在进行翻译和本地化之后，可能会需要占据更多的空间。考虑到这一点，设计表格时尽可能多留出40%的空间。
- 在 DITA 中，你可以在单元格中插入图片。不过，在单元格中最好还是使用图标替代图片。
- 在创建表格时，就要考虑文档发布后的格式问题。表格的格式受屏幕尺寸的影响比较大。比如在小屏设备上（比如移动设备），一些表格可能会变得很难看。
- 有些情况下，使用其他元素替代表格可能会更好一些。比如，如果用定义列表替代表格。在不同的文档中，定义列表可以被设计成不同的格式，可以是表格，也可以是类似于术语表的样子。
