# 表格简介

表格是介于格式和结构化数据之间形式，有点两不靠。然而，展现内容的最佳方式也往往非它莫属。

在 DITA 中，表格有两种类型：简单表格和 CALS 表格。

在 DITA 中，表格都是由行组成的。

## 简单表格

简单表格，顾名思义，就是一种非常简单的表格。对于能完美地划分到一个个横平竖直、四四方方的小方格中的内容，简单表格就是不二选择。

在简单表格中，自定义的空间也很小。你可以给简单表格添加标题行，但不能给简单表格添加标题，不能跨列或跨行合并单元格，也不能设置列宽。

你可以使用 `<simpletable>` 元素创建简单表格。

基于 `<simpletable>` 元素，DITA还另外定制了两种特殊的表格：

- `<properties>` - 属性表，只能用在参考型主题中。
- `<choicetable>` - 选项表，只能用在任务型主题中。

## CALS 表格

CALS 表格是一种支持 CALS 表格模型的表格。CALS 表格模型是在 XML 中表示表格的一种标准，最初是由美国国防部开发的。

CALS 表格支持一些复杂的表格结构。在 CALS 表格中，你可以给表格添加标题，可以跨行或跨列合并单元格，可以为表格行分组，还可以精确地设置列宽等。

你可以使用 `<table>` 元素创建 CALS 表格。

!!! tip "小贴士"
    HTML 中的表格也使用了 CALS 模型。如果你熟悉 HTML 中的表格元素，学习 DITA 中的表格时肯定能发现很多相似之处。
