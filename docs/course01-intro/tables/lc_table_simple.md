# 简单表格

简单表格（`<simpletable>`）的后代元素如下：

| 元素        | 名称             | 数量                                                                       |
|-------------|----------------|-----------------------------------------------------------------------------|
| `<sthead>`  | 简单表格的标题行 | 每个简单表格中最多只能有一个标题行。                                           |
| `<strow>`   | 简单表格的表格行 | 每个简单表格中至少要有一个表格行，也可以有多个表格行。                           |
| `<stentry>` | 简单表格的单元格 | 每个表格行中可以包含任意数量的单元格，但各行中的单元格数量必须相等，包括标题行。   |

!!! note "注意"
    上面的表格是一个简单表格，可以使用`<simpletable>`元素创建。

在简单表格的单元格中，既可以添加文本，也可以插入常用的块元素和行内元素。

下面是一个简单表格示例。示例表格中有一个标题行、两个表格行，每行都分成了两列。

```xml
<simpletable>
  <sthead>
    <stentry>第一列的列标题</stentry>
    <stentry>第二列的列标题</stentry>
  </sthead>
    <strow>
    <stentry>第一行，第一列</stentry>
    <stentry>第一行，第二列</stentry>
  </strow>
  <strow>
    <stentry>第二行，第一列</stentry>
    <stentry>第二行，第二列</stentry>
  </strow>
</simpletable>
```

上面的表格会显示如下：

--8<-- "sample_snippet.md:start"
| 第一列的列标题 | 第二列的列标题 |
|----------|----------|
| 第一行，第一列  | 第一行，第二列  |
| 第二行，第一列  | 第二行，第二列  |
--8<-- "sample_snippet.md:end"
