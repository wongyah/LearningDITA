# 安全信息

使用 `<note>` 元素编写安全信息，比如注释、小心和警告等。
 
```xml
<note>大多数钻水鸭都行动敏捷，一下子就能飞走。接近这些鸭子的时候，一定慢慢地靠近！</note>
```

你可以将安全信息设置为不同的类型，只要为 `<note>` 元素设置一个 `type` 属性即可。在 DITA 中，`type` 属性有一些预定义的属性值：

- `note`（默认值）
- `attention`
- `danger`
- `caution`
- `important`
- `tip`

```xml
<note type="warning">不要给鸭子喂面包。面包不是鸭子的天然食物，可能会损害它们的健康。最好还是给它们喂葡萄或玉米渣吧！</note>
```

预定义的属性值都是最常用的安全信息类型。除此之外，你也可以自定义安全信息的类型。只要先将 `type` 属性的属性值设置为 `other`，然后再将 `othertype`属性的属性值设置为你需要的安全信息类型即可。例如：

```xml
<note type="other" othertype="自定义的安全信息类型"> 不要给鸭子喂面包。面包不是鸭子的天然食物，可能会损害它们的健康。最好还是给它们喂葡萄或玉米渣吧！</note>
```
