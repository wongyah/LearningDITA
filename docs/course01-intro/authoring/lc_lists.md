# 无序列表和有序列表

在 DITA 中，最常用的列表类型是无序列表（`<ul>`）和有序列表（`<ol>`）。无序列表也叫做项目符号列表，有序列表也叫做数字列表。

无论是无序列表还是有序列表，都必须包含至少一个列表项（`<li>` 元素）。在列表项中，既可以插入文本，也可以插入绝大多数常见的块元素和行内元素。下面是一个非常简单的有序列表示例：

```xml
<p>鸭子的一生与大多数鸟类相似：</p>
<ol>
    <li>鸭蛋</li>
    <li>孵化</li>
    <li>雏鸭</li>
    <li>小鸭子</li>
    <li>成年鸭</li>
</ol>
```

注意到没有，上面的有序列表里并没有数字编号。等到生成文档时，数字编号会被自动添加到有序列表中，就像 HTML 中那样。不过，大多数可视化编辑器都设计得非常友好，在显示有序列表时就会带上数字编号。

有序列表可以用来编写具有一定逻辑顺序的内容。如果要介绍流程或过程方面的内容，最好使用任务型主题中的 `<steps>` 元素。

无序列表和有序列表中都能且只能嵌套一级子列表，只要在 `<li>` 元素中再插入一个 `<ul>` 元素或者 `<ol>` 元素即可。

```xml
<p>鸭子的特点如下：</p>
<ul>
  <li>鸭掌带有脚蹼，特别适合游泳。</li>
  <li>鸭腿比其他水禽的腿短。</li>
  <li>鸭嘴与众不同。
    <ul>
      <li>鸭嘴扁平，可以滤食</li>
      <li>鸭嘴细长，可以捕鱼（比如秋沙鸭）。</li>
    </ul>
</li>
</ul>
```

生成文档时，列表中的项目符号或数字编号使用哪种样式取决于样式表以及列表所在的层级。子列表的缩进距离，取将于样式表。

除了无序列表，DITA 还定义了一种简单列表（`<sl>`）。如果一个列表的列表项都是由几个单词组成的简单内容，使用简单列表就可以了。简单列表的列表项使用 `<sli>` 元素。

```xml
<p>鸭子的种类如下：</p>
<sl>
    <sli>栖鸭</sli>
    <sli>钻水鸭</sli>
    <sli>潜水鸭</sli>
</sl>
```
