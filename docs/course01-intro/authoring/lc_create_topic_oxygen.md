# 在 Oxygen 中创建主题

在文本编辑器中阅读 DITA 文件应该还是有点难的。没有高亮显示，元素的层级结构也不大容易辨认（因为空格和换行在XML中没有什么实质性的含义）。大多数人还是喜欢使用可视化编辑器（比如 [Oxygen XML编辑器](https://www.oxygenxml.com/)）编辑DITA文件，因为DITA文件中的内容会带格式显示，比较容易阅读。

!!! note "注意"
    可视化编辑器（比如 Oxygen XML 编辑器）的编辑界面虽然看起来和 Word 软件差不多，但它并不是所见即所得的。不要将 DITA 内容在可视化编辑器显示出来的格式（比如换行、字体、字号等）当成文档的最终格式。

要在 Oxygen XML 编辑器中创建主题，请按以下步骤操作：

1. 在主菜单中选择【文件】>【新建】按钮。
2. 在新建对话框中，选择【框架模板】>【DITA】>【Topics】>【Topic】，然后点击【创建】。Oxygen XML 编辑器会新建一个主题，新建的主题中包含一些占位符。

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE topic PUBLIC "-//OASIS//DTD DITA Topic//EN" "topic.dtd">
<topic id="topic_xks_f1r_bs">
    <title></title>
    <body>
        <p></p>
    </body>
</topic>
```

Oxygen XML 编辑器会为每个新建的主题自动生成一个具有唯一性的 ID。如果需要，你可以将 ID 修改得更加语义化一些。但修改时一定要记住，ID 必须具有一性，而且必须是合法的。在写作模式下，将标签的显示模式设置为`显示标签`，你会看到如下界面：

![截图：在 Oxygen XML 中新建主题的界面](https://pic1.imgdb.cn/item/6891cc3458cb8da5c8066566.png)

现在，在显示 “p”（`<p>` 元素中的占位符）的位置点击一下，你就可以输入内容了。如果要添加一个新的段落，按两下回车键即可。如果要添加其他元素，按一下回车键会在光标处打开一个下拉菜单。然后，从下拉菜单中选择需要的元素即可。
