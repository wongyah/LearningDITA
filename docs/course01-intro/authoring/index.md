# 使用DITA创建内容

## 学习目标

- 学会使用文本编辑器创建 DITA 主题。
- 学会使用Oxygen XML编辑器创建 DITA 主题。
- 学会在主题中插入注释、小心和警告等安全信息。
- 学会在主题中使用无序列表和有序列表。
- 学会区分块元素和行内元素。
