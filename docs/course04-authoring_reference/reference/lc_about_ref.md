# 参考型主题简介

参考型主题主要用来说明"是什么"，比如：

- 这里应该输入什么值？
- LED 闪烁三次是什么意思？
- 应该使用什么命令参数？
- 这个函数可能返回哪些状态值？
- 这条报错是什么意思？

参考型主题提供某项具体信息。概念型主题主题通常提供一般背景信息并说明"为什么"，而参考型主题则提供具体信息。参考型主题的典型读者会根据需要查找信息，找到后就立即回去做他们正在做的事情，通常不会阅读或浏览多余的信息。

参考型主题的内容格式由写作团队决定，而且最好写进写作指南里。本讲只通过示例展示其中一种。

我们此前介绍过的很多元素都可以在参考型主题中使用。本课将重点介绍一些新元素。

参考型主题主要分为两大类：

- 由一个个独立的主题组成，每个主题只包含少量的表格或图。例如：

    - 设备的技术参数表、具体的值或公差

    - 设备的端口位置图或引脚布局图

- 由多个相关的主题组成，每个主题只包含一项信息。通常，这些主题都采用平行结构，读者可以在相似的位置找到相似的信息。例如：

    - 命令行的参考文档
    - API 函数的参考文档
    - 错误代码的参考文档
    - 设备的数据手册
