# 创建模板

如果参考文档由多个主题组成，每个主题包含一条命令、一个函数调用或者其他程式化内容，这些主题的内容结构应该相同。例如，在命令行参考文档中，每个主题可能都有简介、语法说明、参数说明、详细阐述、示例和错误提示。这样，无论是哪个主题，读者都可以在相同区域找到相似的内容。

在 `<refbody>` 元素中，使用 `<section>` 元素划分小节，每个小节包含一项内容，使用 `<title>` 元素为小节添加标题。

如需要创建多个类似的主题，可以使用模板。模板是独立的主题，里面有可以复用的结构，但不需要有太多内容。例如，在参考型主题模板中，可以设置一些固定的小节，每个小节包含一个 `<title>` 元素。在每个小节中，输入一些占位文本，让写作人员一看就知道这是一个占位章节。

!!! note "注意"
    模板的根元素（`<reference>`）必须要设置一个 `id` 属性，并且要让写作人员知道如何防止使用重复的 `id` 值。例如，将 `id` 属性值的占位文本设置为 `id="DUMMY"`，写作人员一看就知道要使用一个合法的 `id` 值替换掉它。
