# 使用关系表创建链接

命令行或 API 参考文档通常都有一个特点，每个主题都要插入相关命令或函数的链接。例如，设备安装命令主题中要插入设备卸载命令的链接，端口配置命令主题中要插入其他端口命令的链接，网络连接启用函数主题中要插入网络管理员下一步经常需要调用的函数链接。

DITA 出现之前，这些相关链接维护起来很不容易，尤其是那些正在开发的产品。如果增删或修改组件，就得查找并修改所有相关链接。

如果使用 DITA 中的关系表创建相关链接，DITA-OT 会在生成文档时批量生成链接。如果增删或修改组件，你只需要在关系表中修改一两个地方，下次再生成文档时，所有相关链接就会随之更新。

需要注意的是，如果要将非结构化内容转换为 DITA，相关链接可能会在转换过程中被删除（至少会被注释掉）。
