# 最佳实践

## 学习目标

- 学会为参考型主题创建模板。
- 了解使用关系表创建链接的好处。
- 学会使用领域元素。

## 学习时长

大约 1 小时。

## 课程简介

本讲将教你如何按照最佳实践编写参考型主题，包括如何为参考型主题创建模板、如何使用关系表管理链接以及如何使用领域元素增强语义。
