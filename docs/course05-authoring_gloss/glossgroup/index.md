# 创建术语词条主题

## 学习目标

- 学会区分术语词条主题和术语分组主题
- 了解术语分组主题的基本结构

## 学习时长

大约 15 分钟。

## 课程简介

本讲将教你如何新建术语分组主题，并在主题中插入常用元素。

!!! note "注意"
    本讲的主要内容是术语分组主题中元素的基本用法。如果你想了解每个元素的详细用法，请参见 [《OASIS DITA 1.3 规范》：术语分组](https://docs.oasis-open.org/dita/dita/v1.3/errata01/os/complete/part3-all-inclusive/langRef/technicalContent/glossgroup.html#glossgroup)。
