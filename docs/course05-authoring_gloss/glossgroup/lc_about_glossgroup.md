# 术语分组主题简介

虽然使用术语词条主题有很多好处，但如果术语词条文件太多，不好管理。使用术语分组主题，可以将很多术语词条放在一个文件里。

术语分组主题可以包含一个或多个术语词条，词条的结构和术语词条主题一模一样。

一开始，你可能会觉得术语分组主题用起来很方便，但长期来看，这么做也有一些负面影响：

- **内容复用**。如果将术语词条放进术语分组主题中，复用起来会比较困难。
- **归属**。术语分组中的词条，通常是专为某个产品或团队编写的。往术语分组中集成新词条，会比较难。
- **内容本地化**。如果要翻译术语表，其中的词条可能需要根据目标语言的习惯重新排序。更新术语分组主题中的词条，可能会对译文的排序过程产生负面影响。
- **引用**。如果使用术语分组主题集中管理词条，引用起来会难得多。

术语词条主题和术语分组主题各有所长，使用时要根据实际需求和应用场景来决定哪一个更合适。
