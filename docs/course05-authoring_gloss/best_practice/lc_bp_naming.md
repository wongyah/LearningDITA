# 文件名称和主题 ID

无论使用哪种管理方式（文件管理系统或内容管理系统），为 DITA 文件命名或设置 `id` 属性时请遵循以下原则：

- 术语词条主题的文件名尽可能以 `g_` 开头。文件名的剩余部分应体现出术语词条中的术语是什么。遵循以上文件命名原则，在文件管理系统中查找词条时会更加方便。在文件名中，使用下划线（`_`）作为单词分隔符，不要使用空格（如果 DITA 文件的文件名中含有空格，容易引起错误）。
- 术语词条主题的 `id` 应该与该主题的文件名（去掉扩展名 `.dita`）相同。如果 `id` 属性与文件名中的术语相同，`id` 属性开头的 `g_` 可以省略。例如，术语词条主题的文件名是 `g_mallard.dita`，`id` 属性的属性值应该设置为 `g_mallard` 或 `mallard`。
- 到现在为止，本课程还没有讲到键（DITA 中的一个重要概念）。不过，我们还是建议使用 `id` 属性的属性值作为键名。
