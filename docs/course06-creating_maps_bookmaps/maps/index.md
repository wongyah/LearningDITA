# 创建 DITA 导图

## 学习目标

- 了解 DITA 导图（以下简称导图）的功能和结构。
- 学会新建导图，以及如何使用 `<topicref>` 和 `<mapref>` 元素。
- 学会创建具有层级结构的导图。

## 学习时长

大约 45 分钟。

## 课程简介

本讲将教你如何新建导图，以及如何在导图中插入主题引用和导图引用（即子导图）。
