# 新建 DITA 导图

DITA 导图（以下简称导图）主要用来收集、定义和管理主题之间的关系。导图中通常包含以下内容：

- 与某个产品有关的所有概念型主题和参考型主题。
- 为该产品提供操作说明的所有任务型主题。
- 与该产品有关的术语表。

虽然 DITA 主题可以独立发布，但技术写作人员通常使用导图将主题们收集到一起，以便于发布。

使用导图可以让发布流程更灵活，也便于进行内容复用。如果一段内容适用多个产品（比如安全信息），你只需要将其编写成一个主题，并在多个导图中引用即可。

导图中也可以引用其他导图。这样，你就可以将若干组主题组织在一起。例如，你可以为每个产品制作一张导图，再将这些导图收集到一张总导图中，形成一个产品系列。

导图中可以包含元数据，比如产品信息、版权声明和发布日期。导图中的元数据，可以用来管理和发布内容，也可以让内容查找更便捷。

一个最简单的导图，至少要包含一个根元素 `<map>`。导图（`<map>`）中可以包含以下元素：

- `<title>` 元素，可以为导图添加标题（比如“某某产品使用说明书”）。`<title>` 元素中的文本，也可以用作发布后的文档名称。
- 任意数量的 `<topicref>` 元素，可以往导图中插入主题（即引用主题）。`<topicref>` 元素可以自嵌套。
- 任意数量的 `<mapref>` 元素，可以往主导图中插入其他导图（即引用导图）。
- 任意数量的 `<reltable>` 元素，可以在导图中定义主题与主题之间的关系。

!!! note "注意"
    如果你想深入了解 `<map>` 元素，请参见 《OASIS DITA 1.3 规范》中的[导图](https://docs.oasis-open.org/dita/dita/v1.3/errata01/os/complete/part3-all-inclusive/langRef/base/map.html#map)一节。

## 随堂练习

1. 为 `maps_bookmaps_samples/samples/_m_ducks_start.ditamap` 文件复制一个副本，然后在编辑器中打开。

    !!! note "注意"
        如果你使用的是支持 DITA 的编辑器，请使用文本模式，不要使用写作模式或者其他可视模式。

    你看到的文件内容应该是这样的：

    ```xml
    <?xml version="1.0" encoding="UTF-8"?>
    <!DOCTYPE map PUBLIC "-//OASIS//DTD DITA Map//EN" "map.dtd">
    <map id="ducks">
      <title>xyz</title>
    </map>
    ```

    - 第一行（以 `<?xml` 开头）是XML声明。XML声明是XML文件的一个标准组成部分。
    - 第二行是文档类型声明（即DOCTYPE声明），用来声明该文件是一张 DITA 导图。
    - 第三行是 `<map>` 元素的开始标签，还带有一个属性值为 `ducks` 的 `ID`。
    - 第四行是 `<title>` 元素，其内容是该导图的标题。
    - 第五行是 `<map>` 元素的结束标签，表示 `<map>` 元素在此结束。

2. 在 `<title>` 元素中，编辑标题文本如下：

    ```xml
    <?xml version="1.0" encoding="UTF-8"?>
    <!DOCTYPE map PUBLIC "-//OASIS//DTD DITA Map//EN" "map.dtd">
    <map id="ducks">
      <title>鸭子</title>
    </map>
    ```

    现在，导图的基本结构已经搭建好了。你可以插入主题引用了！
