# 创建书籍导图

## 学习目标

- 了解书籍导图的功能和结构。
- 学会新建书籍导图和 `<chapter>` 元素的使用方法。
- 学会在章节中使用 `<topicref>` 和 `<mapref>` 元素。
- 学会创建具有层级结构的书籍导图。

## 学习时长

大约 45 分钟。

## 课程简介

本讲将教你如何新建书籍导图，以及如何在书籍导图中搭建书籍式的内容结构。
