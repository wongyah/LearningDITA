# 书籍导图简介

书籍导图可以创建书籍式的内容结构，是在导图的基础上进行的功能扩展。书籍导图和导图的结构非常相似，但书籍导图可以包含更多元素，例如章节、附录、部分（包含若干章节或附录）、前言和后记。对于大规模内容发布，这一点非常有用。书籍导图比导图更灵活，非常适合发布书籍式内容。

到底应该用导图还是书籍导图，主要取决于出版物和交付流程。如果要交付在线内容，比如 HTML 或在线帮助，使用导图。如果要交付印刷版或 PDF 格式的内容，使用书籍导图。如果既要发布印刷版要要发布在线格式，推荐使用书籍导图。

书籍导图和导图的一个主要区别是划分章节的能力。在导图中，你可以通过嵌套主题创建层级结构。在书籍导图中，一级主题通常叫做“章”（也可以设置成附录）。虽然主题的层级结构相同，但把一级主题称为“章”可以提供更多语义。使用书籍导图发布文档时，文档发布程序可以为章标题单独设置格式，以区别于其他级别的标题。

在书籍导图中，你还可以使用 `<bookmeta>` 元素定义元数据。`<bookmeta>` 元素主要用来说明出版物的具体信息。该元素只能在 `<bookmap>` 元素中使用，不能在 `<map>` 元素中使用。这也是书籍导图比导图更适合发布书籍式内容的一个重要原因。
