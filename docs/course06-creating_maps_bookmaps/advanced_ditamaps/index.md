# 高级元素

## 学习目标

- 了解导图和书籍导图中的元数据以及它们之间的区别。
- 了解 `<frontmatter>` 和 `<backmatter>` 元素的用途和插入位置。
- 学会使用 `<booklists>` 元素生成目录和索引。

## 学习时长

大约 45 分钟。

## 课程简介

本讲将介绍导图和书籍导图中的高级元素，包括元数据、内容分组以及 `<booklists>` 元素的使用方法（比如生成目录或索引）。
