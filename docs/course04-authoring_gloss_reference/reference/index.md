# 创建参考型主题

## 学习目标

- 了解参考型主题的用途[
- 了解参考型主题的基本结构
- 了解 `<refsyn>` 和 `<properties>` 元素的用途

## 学习时长

大约 45 分钟。

## 课程简介

本讲将教你如何新建一个参考型主题以及如何在参考型主题中添加常用元素。

!!! note "注意"
    本讲的主要内容是这些元素的基本用法。如果你想了解每个元素的详细用法，请参见 《OASIS DITA 1.3 规范》中的[参考型主题](https://docs.oasis-open.org/dita/dita/v1.3/errata01/os/complete/part3-all-inclusive/langRef/technicalContent/reference.html#reference)。
