# 术语词条主题和术语分组主题简介

术语词条主题主要用来为术语或概念下定义。

每个术语词条都包含一个术语和定义。也就是说，一个术语词条就是一个文件。

有时候，术语词条文件太多，不好管理。使用术语分组主题，可以将很多术语词条放在一个文件里。术语分组主题可以包含一个或多个术语词条，词条的结构和术语词条主题一模一样。

一开始，你可能会觉得为每个术语词条都创建一个主题（即一个文件）很麻烦。但这么做有很多好处：

- **内容复用**。你创建的术语词条，可以用在很多产品中。除了你自己之外，其他团队成员也可以使用。如果将术语词条放进术语分组主题中，复用起来会比较困难。
- **归属**。术语分组中的词条，通常是专为某个产品或团队编写的。往术语分组中集成新词条，会比较难。
- **内容本地化**。如果要翻译术语表，其中的词条可能需要根据译文的习惯重新排序。更新术语分组主题中的词条，可能会对译文的排序过程产生负面影响。
- **引用**。你可以在正文中引用术语词条。如果每个术语词条都是一个独立的文件，引起起来会很方便。如果使用术语分组主题集中管理词条，引用起来会难得多。

虽然使用术语词条主题有很多好处，但术语分组主题仍然有用武之地。因此，本讲既教你如何新建术语词条主题，也教你如何新建术语分组主题。
