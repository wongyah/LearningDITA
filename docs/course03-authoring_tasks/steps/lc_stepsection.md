# 中断操作流程

有两个元素可以为操作流程补充额外信息：

- 使用 `<stepsection>` 元素在两个操作步骤之间添加注释。
  如果你要对操作流程进行一下说明，比如“后续步骤重点关注 *x* 组件”或者“后面的两个操作步骤必须在 *y* 环境下进行，`<stepsection>` 元素就派上用场了。

- 使用 `<note>` 或 `<hazardstatement>` 元素为操作步骤（`<step>`）或者子步骤（`<substep>`）添加安全信息。`<note>` 和 `<hazardstatement>` 元素必须位于 `<cmd>` 元素的前面。
  在阅读或执行 `<cmd>` 中的指令之前，通常使用 `<note>` 或 `<hazardstatement>` 元素向用户警示风险或危险。

## 随堂练习

1. 打开上一节使用的练习文件 `l_task_start.dita`。

2. 在最后一个 `<step>` 元素的后面，插入一个 `<stepsection>` 元素。

    ```xml
    ...
    </step>
    <stepsection>
    </stepsection>
    ```

3. 在 `<stepsection>` 元素中添加内容如下：

    ```xml
    ...
    <stepsection>
      <p>一旦识别出了这只鸭子的种类，你就可以花些时间观察它的行为。</p>
    </stepsection>
    ```
    根据最佳实践，元素中的文本应该放在 `<p>` 元素中。

4. 在 `<stepsection>` 元素的后面，插入一个 `<step>` 元素（其中包含一个 `<note>` 元素），并添加内容如下：

    ```xml
    ...
    </stepsection>
    <step>
     <note>观察鸭子的行为时，不要打扰到它们。如果它们意识到周围有人，行为就会不一样。</note>
    </step>
    ```

5. 在 `<note>` 元素的后面，插入一个 `<cmd>` 元素，并添加内容如下：

    ```xml
    ...
      </note>
      <cmd>观察鸭子们是如何互动的、它们吃什么或者它们如何以及何时整理羽毛。</cmd>
    </step>
    ```

6. 4. 对照[随堂练习的参考答案] (`lesson2/l_task_steps.dita`)，自行批改一下你刚刚完成的练习作业 (`l_new_task_start.dita`)。
