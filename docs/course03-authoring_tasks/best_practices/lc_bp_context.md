# 提供适当的上下文

为了让用户知道他为什么要执行一项任务或者该任务到底是做什么的，你应该在 `<context>` 元素中提供足够的上下文。不要使用 `<context>` 元素编写详细的概念性内容或提供详细的背景信息。

如果需要提供额外的概念性内容、背景信息或操作原则，请创建概念型主题并在任务型主题中添加指向该概念型主题的链接。

请注意，`<context>` 元素和 `<shortdesc>`（简要描述）元素的用法看起来可能很相似。在任务型主题中，两者都可以用来编写与任务目的相关的内容。不过，`<shortdesc>` 元素通常用来编写简单的内容，作为链接或搜索结果页中的预览文本，而 `<context>` 元素可以用来编写稍微详细一点的内容，比如与任务目的有关的额外信息。
