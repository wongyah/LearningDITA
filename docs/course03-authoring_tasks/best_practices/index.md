# 最佳实践

## 学习目标

- 了解编写任务型主题的最佳实践。
- 学习任务型主题中的最佳实践范例。

## 学习时长

大约 1 小时。

## 课程简介

本讲将教你如何按照最佳实践编写任务型主题。你将学习如何进行任务规划、如何为任务提供合适的上下文、一个任务中包含多少操作步骤比较合适、什么情况下应该使用子步骤以及如何发现内容复用的机会。
