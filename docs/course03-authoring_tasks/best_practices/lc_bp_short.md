# 操作步骤的数量要合理

在 DITA 中，任务型主题并没有限制操作步骤的数量。不过，任务型主题中的内容不应太长。

尽管任务型主题的长度是否合适主要依赖主观判断，但如果一个任务中包含的操作步骤太多，可能会让用户觉得不知所措，尤其是初级用户。

一个任务型主题中最多应该包含多少个操作步骤，并没有一个绝对的数字作为标准。有些技术写作人员将操作步骤的数量控制为 10 个或以下，不过偶尔也可以破例。如果一个操作流程中有 20 个以上的操作步骤，那肯定是不合适的。

较长的任务型主题还有一个副作用，就是用户在操作过程中可能经常忘记自己到底执行到哪一步了。如果有一长串非常相似的操作步骤，这一点会变得尤为明显。

还有一种超短的任务型主题，比如一个主题中只有一两个操作步骤。如果你的目的是要编写一组大而全的任务型主题，上述情况可能无法避免。如果你编写的任务型主题大多数都比较长，偶尔出现几个只有一两个操作步骤的超短主题是完全可以接受的。
