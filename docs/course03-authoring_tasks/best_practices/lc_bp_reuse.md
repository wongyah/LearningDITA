# 发现内容复用的机会

任务型主题中有很多内容复用的机会，虽然到目前为止 LearningDITA 课程尚未讲到内容复用（这是 DITA 的优势之一）。

在任务型主题中编写操作步骤时，留意那些在多个任务中都相同的步骤，比如：

```xml
<step>
  <cmd>点击<uicontrol>确定</uicontrol>.</cmd>
</step>
```

你可能需要编写一系列任务型主题，每个主题的操作流程都以相同的操作步骤开始，比如停机或拆除检修面板。同理，有些任务型主题的操作流程可能会以一组相同的操作步骤结束。这些都是内容复用的好机会。

在任务型主题中，另一个经常使用内容复用的地方是标准文本，比如操作步骤中的安全信息（小心、警告等）。

除了 `<step>` 元素，任务型主题中的 `<prereq>`、`<example>`、`<choices>` 和`<choicetable>` 元素也藏着很多内容重用的机会。

本讲的第一部分是《[制定任务规划](lc_bp_planning.md)》。制定任务规范的原因之一是为了内容复用。在制定任务规划时，识别出那些在多个任务中都相同的操作步骤是非常重要的。内容复用的关键是，识别出那些可以进行内容复用的元素，然后将这些元素放在单独的文件中进行管理和维护。经过批准之后，这些文件应该受到保护，仅在必要时才能对它们进行修改。
