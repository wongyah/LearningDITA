# 制定任务规划

人们往往一开始就创建任务型主题、编写主题内容，直到你觉得写完了。然而，这种方式很容易遗漏重要任务，使文档内容不完整。

与想到一个任务就创建一个任务相比，更好的方式是事先规划你需要编写的所有任务。

有很多资源和方法可以帮助你进行任务分析。无论使用哪种资源或方法，最关键的是以下几点：

1. 收集用户的任务需求。
2. 确定需要编写的任务。
3. 搞清楚这些任务的任务范围。
4. 了解用户的能力水平和需求。
5. 根据以上信息制定相应的任务规划。

制定好任务规划之后，你就可以请所有利益相关者审阅完整的任务清单。这些利益相关者包括技术写作人员、编辑、行业专家、其他内容贡献者、项目经理以及其他任何参与内容开发过程的人员。这一步很重要，因为参与者越多，遗漏重要任务的概率越低。

任务清单可以帮助你规划概念型主题、参考型主题和术语主题。对于清单中的每个任务，都要考虑该任务需要什么样的概念型主题和参考型主题来支持。你还可以借助任务识别其中的术语，进而确定需要编写哪些术语主题。
