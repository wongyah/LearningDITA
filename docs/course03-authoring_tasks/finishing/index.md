# 插入收尾性元素

## 学习目标

- 了解 `<result>`、`<example>` 和 `<postreq>` 元素的用途。

## 学习时长

大约 45 分钟。

## 课程简介

插入操作流程后，你可以使用以下三个元素为任务型主题收尾：

- `<result>` 元素主要用来说明任务成功完成后的结果。
- `<example>` 元素主要用来编写整个任务的示例。
- `<postreq>`（读作“postrequisite”，即后置任务）元素主要用来说明下一步要做什么。

!!! note "注意"
    本讲的主要内容是这些元素的基本用法。如果你想了解每个元素的详细用法，请参见 [《OASIS DITA 1.3 规范》中的任务型主题一节](https://docs.oasis-open.org/dita/dita/v1.3/errata01/os/complete/part3-all-inclusive/langRef/technicalContent/task.html#task)。
