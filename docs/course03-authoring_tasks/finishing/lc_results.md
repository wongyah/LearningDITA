# 插入任务结果

在 `<steps>` 元素的后面，你可以使用 `<result>` 元素来说明任务成功完成后的结果。

`<result>` 元素和 `<stepresult>` 元素类似。唯一的不同是，`<stepresult>` 元素说明的是完成一个操作步骤之后的结果，而 `<result>` 元素说明的是完成整个任务之后的结果。

在 `<stepresult>` 元素中，你可以编写确认消息、验证操作结果的小测试或者一个简短的祝贺消息。

## 随堂练习

1. 打开上一讲使用的练习文件 `l_task_start.dita`。

2. 在 `<steps>` 元素的后面，插入一个 `<result>` 元素。

    ```xml
    ...
        </steps>
        <result>
        </result>
      </taskbody>
    </task>
    ```

3. 在 `<result>` 元素中添加内容如下：

    ```xml
    <result>
      <p>新鲜的空气、适度的运动和见到野鸭的兴奋感，会让你倍感幸福。</p>
    </result>
    ```

    根据最佳实践，元素中的文本应该放在 `<p>` 元素中。
