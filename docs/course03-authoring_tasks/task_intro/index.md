# 创建任务型主题

## 学习目标

- 创建一个任务型主题
- 学会区分严格任务和通用任务
- 了解严格任务主题的文档类型（DOCTYPE）
- 学会在任务型主题中插入根元素
- 了解 `<prereq>` 和 `<context>` 元素的用途

## 学习时长

大约 45 分钟。

## 课程简介

本讲将教你如何新建一个任务型主题以及如何在任务型主题中插入常用元素。

!!! note "注意"
    本讲的主要内容是这些元素的基本用法。如果你想了解每个元素的详细用法，请参见 [《OASIS DITA 1.3 规范》](https://docs.oasis-open.org/dita/dita/v1.3/errata01/os/complete/part3-all-inclusive/langRef/containers/concept-elements.html#concept2)。
