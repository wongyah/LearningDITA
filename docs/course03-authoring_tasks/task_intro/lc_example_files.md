# 练习资料

请前往[百度网盘]{: target="_blank"}下载本课的练习资料 (`task_samples` 文件夹)，并将其保存在一个容易查找的地方。

## 资料说明

在 `task_samples` 文件夹中，有四个子文件夹：`lesson1`、`lesson2`、`lesson3` 和 `lesson4`。每个子文件夹对应一讲，里面都有四个 DITA 文件：

- `l_filename_start.dita`：一个空文件，用来进行随堂练习。
- `l_filename.dita`：随堂练习的参考答案，用来对照检查随堂练习的成果。
- `l_filename_exercise_start.dita`：一个空文件，用来进行课后练习。
- `l_filename_exercise.dita`：课后练习的参考答案，用来对照检查课后练习的成果。

什么时候应该使用哪个文件进行练习，在课程中都有明确说明。在练习时，每完成一步都要保存一下文件，以免内容丢失。

## 注意事项

每次开始新的一讲之前，将上一讲的练习作业复制一份用于后续练习。这样的话，如果你在练习中出了差错或者遇到文件意外损坏之类的情况，你就可以重新复制一份练习资料再练习一次或者快速修复文件。

在课程讲解和练习中，我们会一直使用 DITA 源代码。大多数 DITA 编辑工具都有自动补全之类的功能，可以极大地简化添加元素的过程。例如，当你输入元素的开始标签之后，DITA编辑器会帮你自动补全对应的结束标签。因此，你基本不需要从零开始一个字符一个字符地敲每一个代码。
