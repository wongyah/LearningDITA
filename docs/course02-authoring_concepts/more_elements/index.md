# 更多元素

## 学习目标

- 学习更多元素，以及如何在概念性主题中使用这些元素的最佳实践。
- 学会在概念型主题中使用`<b>`、`<i>`、`<u>`、`<term>`、`<cite>`、`<varname>`、`<sub>`、`<sup>`、`<dl>`、`<menucascade>`和`<fn>`元素。

## 学习时长

大约 1 小时。

## 课程简介

除了基本元素之外，你可能还需要在概念型主题中使用语义更加明确的元素、图片和表格。你可能需要强调某些重要的词汇或短语，或者使用更加高级的方式定义术语或提供参考信息。

在DITA中，使用频率比较高的行内元素有`<b>`、`<i>`、`<u>`、`<sub>`和`<sup>`元素。此外，还有语义更加明确或者可以提供更多额外信息的行内元素，比如`<term>`、`<cite>`和`<varname>`。

其他有用的元素还有，用来插入脚注的`<fn>`、用来说明软件菜单项顺序的`<menucascade>`，以及用来编写术语及其定义的定义列表`<dl>`。

本讲将介绍这些元素，并教你如何在概念型主题中使用它们。和本课中介绍的其他元素一样，这些元素不只能在概念型主题中使用，也可以在其他类型的主题中使用（比如任务型主题和参考型主题）。

!!! note "注意"
    本讲的主要内容是这些元素的基本用法。如果你想了解每个元素的详细用法，请参见 [《OASIS DITA 1.3 规范》中的概念型主题一节](https://docs.oasis-open.org/dita/dita/v1.3/errata01/os/complete/part3-all-inclusive/langRef/containers/concept-elements.html#concept2)。
