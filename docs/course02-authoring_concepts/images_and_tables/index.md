# 图片和表格

## 学习目标

- 了解在概念型主题中使用图片的最佳实践。
- 学会在概念型主题中使用 `<fig>` 和 `<image>` 元素。
- 了解在概念型主题中添加表格时使用的基本元素
- 学会在概念型主题中使用 `<simpletable>` 和 `<table>` 元素。

## 学习时长

大约 90 分钟。

## 课程简介

在概念型主题中，图片和表格可以让内容变得更直观、更清晰。

`<image>` 元素可以单独使用，也可以作为 `<fig>` 元素的子元素使用。你可以通过指向图片的网址或者本地路径的链接，将图片添加到主题中。

你可以使用 `<simpletable>` 和 `<table>` 元素创建表格，以清晰、直观的方式呈现事实信息。如果表格很简单，周围还有文本内容，就使用 `<simpletable>` 元素。如果表格很复杂，就使用 `<table>` 元素。

本讲将教你如何在概念型主题中插入图片和表格。和本课中介绍的其他元素一样，图片和表格不只能在概念型主题中使用，也可以在其他类型的主题中使用（比如任务型主题和参考型主题）。

!!! note "注意"
    本讲的主要内容是这些元素的基本用法。如果你想了解每个元素的详细用法，请参见 [《OASIS DITA 1.3 规范》](https://docs.oasis-open.org/dita/dita/v1.3/errata01/os/complete/part3-all-inclusive/langRef/containers/element-quick-reference.html#element-quick-reference)。
