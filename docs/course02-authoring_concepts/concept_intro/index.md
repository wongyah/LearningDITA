# 创建概念型主题

## 学习目标

- 创建一个概念型主题。
- 了解概念型主题中的文档类型声明（DOCTYPE）。
- 学会新建概念型主题。
- 学会使用一些基本元素，比如`<p>`、`<ul>`、`<ol>`和`<note>`。

## 学习时长

大约 45 分钟。

## 课程简介

概念型主题主要用来编写与某个主题相关的内容。

概念型主题可以帮助读者理解一个概念或了解一条指令的用途。除了基本信息之外，概念型主题还可以为某个主题提供背景信息或概念性信息。

在典型的概念型主题中，段落和列表是用得最多的元素。不过，你也可以使用图片、表格以及其他很多元素。为了让内容结构更清晰，你甚至还可以将一个概念型主题划分成多个小节。

本讲将教你如何新建一个概念型主题以及如何在主题中添加常用元素。除了`<conbody>`元素之外，你在本课（包括本讲）中学到的所有元素不只能在概念型主题中使用，也可以在其他类型的主题中使用（比如任务型主题和参考型主题）。

!!! note "注意"
    本讲的主要内容是这些元素的基本用法。如果你想了解每个元素的详细用法，请参见 [《OASIS DITA 1.3 规范》中的概念型主题一节](https://docs.oasis-open.org/dita/dita/v1.3/errata01/os/complete/part3-all-inclusive/langRef/containers/concept-elements.html#concept2)。
