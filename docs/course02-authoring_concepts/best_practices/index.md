# XML简介和最佳实践

## 学习目标

- 了解编写概念型主题的最佳实践。
- 学习概念型主题中的最佳实践范例。

## 学习时长

大约 1 小时。

## 课程简介

本讲将教你如何按照最佳实践编写概念型主题。你将体验内容与格式分离、DITA元素的一致性以及语义丰富的妙处。
