# 内容与格式分离

使用DITA创建结构化内容的一大优势，就是内容与格式分离。与使用格式标记的内容相比，基于内容结构标记的内容具有更加灵活的发布能力。

例如，基于页面布局而创建的非结构化内容可以发布出优质的纸质文档或PDF文档，但在发布HTML文档时会很吃力或者根本发布不出来。然而，由于DITA主题是结构化文档，只有内容，没有格式，就可以在多种发布格式中都表现优异。

习惯使用基于格式的编辑环境（比如桌面发布程序）的写作人员，很容易因为过多考虑内容格式而滥用DITA标签。滥用DITA标签不仅会降低这些标签的价值，还可能产生意想不到的后果：一个被误用的标签可能会在一种格式的文档中实现预期的效果，但在另一种格式的文档中却会引起格式错乱。

滥用DITA标签的后果之一，是强制断行。不要使用`<p>`元素来断行。否则，发布成响应式文档（比如HTML）时就会出问题。如需要在内容（比如，代码示例）中插入断行符，使用`<codeblock>`元素。
