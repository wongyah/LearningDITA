# 创建语义丰富的内容

DITA的优势之一，就是能够创建语义丰富的内容，或者元素标签本身包含与内容有关的信息。

例如，使用`<term>`元素可以让一个词汇在文档中显示为粗体，但元素标签本身表达的信息不仅仅是"显示为粗体"这么简单，它还表示这是一个有定义的术语。

为了充分发挥DITA语义丰富的特点，请将每一段内容都放在最符合其含义和使用方法的元素中。例如，使用`<term>`或`<cite>`元素来强调重要词汇，而不是简单地使用`<b>`或`<i>`。

正确使用主题类型也可以让内容的语义更丰富。例如，使用任务型主题编写分步骤的操作说明，而不是使用概念型主题。这样，DITA为编写操作步骤而设计的内容结构就可以为你所用，可比在概念型主题中使用`<ol>`元素所能表达的信息丰富多了！
