# 元素标签的一致性

由于DITA具有内容与格式分离的特点，在DITA中使用一致的结构和标签可以确保所有的发布格式都能符合预期。

标签不一致会产生一个副作用：混合内容。假设你有一个无序列表，如下：

```xml
<ul>
 <li>文本</li>
 <li>文本</li>
 <li>文本
  <p>文本</p>
 </li>
</ul>
```

在本例中，最后一个列表项中有两个段落。由于`<p>`元素在`<li>`元素中是合法元素，每个段落可以单独标记。但在本例中，就出现了混合内容：最后一个`<li>`元素中的第一行文本直接放在了`<li>`元素中，而另一行文本则放在了`<p>`元素中。这可能会影响该列表在最终文档中的格式。

为了防止出现混合内容，请将`<li>`元素中的所有文本都放在`<p>`元素中，无论`<li>`元素中只有一个段落还是有多个段落：

```xml
<ul>
 <li><p>文本</p></li>
 <li><p>文本</p></li>
 <li>
  <p>文本</p>
  <p>文本</p>
 </li>
</ul>
```

除了`<li>`元素之外，在`<note>`、`<entry>`和`<stentry>`元素中，我们也建议将所有文本都放在`<p>`元素中。为了提高一致性、防止出现混合内容，请将所有不需要使用特定元素的内容都放在`<p>`元素中。
